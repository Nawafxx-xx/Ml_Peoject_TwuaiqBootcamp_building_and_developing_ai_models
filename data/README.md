# Dataset

Place the source file at:

```text
data/raw/heart_disease_risk_2026.csv
```

The repository already includes this file so the notebook can run immediately after cloning. If it is removed, the notebook attempts to download the public dataset with `kagglehub` and restores it to the same location.

Source: [Heart Disease Risk 2026 on Kaggle](https://www.kaggle.com/datasets/uditjain13/heart-disease-risk-2026)

- Rows: 9,000
- Columns: 27
- Target: `has_heart_disease`
- License: CC0 — Public Domain
- Important: This is synthetic data for education and experimentation. It must not be used for clinical diagnosis, screening, or medical decisions.
